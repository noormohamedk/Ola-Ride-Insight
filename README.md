# OLA Ride Insights Dashboard

An end-to-end Data Analytics project that analyzes OLA ride booking data and generates actionable business insights using **MySQL, SQL, Python, Power BI, and Streamlit**.

## Project Overview

The OLA Ride Insights Dashboard is designed to analyze ride-booking data and generate meaningful business insights through interactive dashboards and SQL analytics.

The project helps stakeholders monitor:

* Total Bookings
* Successful Rides
* Cancelled Rides
* Revenue Performance
* Customer Behavior
* Driver Performance
* Vehicle Type Analysis
* Payment Method Analysis
* Customer & Driver Ratings

## Technologies Used

| Technology | Purpose                       |
| ---------- | ----------------------------- |
| MySQL      | Database Management           |
| SQL        | Data Querying & Analytics     |
| Python     | Data Cleaning & Preprocessing |
| Power BI   | Interactive Dashboard         |
| Streamlit  | Web Application Deployment    |

## Database Design

**Database Name:** `OLARideInsights`

**Table Name:** `ola_bookings`

### Important Columns

* Booking_ID
* Customer_ID
* Driver_ID
* Booking_Status
* Vehicle_Type
* Payment_Method
* Ride_Distance
* Booking_Value
* Customer_Rating
* Driver_Rating
* Cancellation_Reason
* Booking_Date
